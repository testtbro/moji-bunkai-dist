# 文字分解 Moji Bunkai（Illustrator プラグイン）

テキストを **文字・行・スペース・結合部（濁点や偏旁などのパーツ）** 単位に分解する
Illustrator 用パネルです。テキストのまま／オブジェクト化を選べます。

対応：Illustrator CC 2019（23.0）以降。macOS / Windows。

## インストール

1. [Releases](../../releases) から最新の `MojiBunkai-<version>.zxp` をダウンロード。
2. 次のいずれかで導入（Mac / Windows 共通）：
   - **ZXP Installer**（aescripts、無料）に `.zxp` をドラッグ＆ドロップ
   - **Anastasiy's Extension Manager** で開く
3. Illustrator を再起動 → **ウィンドウ ＞ エクステンション ＞ 文字分解 Moji Bunkai**。

初回起動時に **Activation key** の入力を求められます。入力して認証すると使えるようになります
（一度認証すれば以後オフラインでも動作）。

## 使い方

1. 選択ツールでテキストオブジェクトを選択（複数可）。
   ※文字ツールで編集中は実行できません（Esc で編集を終了）。
2. パネル左上の**モードアイコンをクリック**して分解方法を切り替え。
   - クリック：次へ ／ Shift＋クリック・右クリック：前へ ／ アイコン下のドットで現在位置
   - 文字ごと → 行ごと → スペースごと → 行・スペースごと → 結合部ごと → 分解なし
3. **出力**（テキスト／オブジェクト）と必要なオプションを選び、**分解**。
4. 結果は元テキストの直上に作成されます。

### 分解モード

| モード | 内容 |
|---|---|
| 文字ごと | 1文字ずつ（濁点付き・異体字・絵文字も1文字として扱う） |
| 行ごと | 改行・折り返しごと |
| スペースごと | スペース（全角/タブ含む）と改行で区切る |
| 行・スペースごと | 単語に分け、行ごとのグループにまとめる |
| 結合部ごと | 離れたパーツ（濁点・偏・旁など）をパスに分解 |
| 分解なし | オブジェクト化のみ |

### アップデート

新しいバージョンが出ると、パネル上部に「○○ が利用できます ［インストール］」が表示されます。
［インストール］で更新できます（✕で閉じても、更新がある限り次回起動時に再表示）。
パネルメニュー（≡）→「最新バージョンを確認」で手動確認も可能です。
